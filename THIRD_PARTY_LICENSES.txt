1. EXECUTIVE COMPLIANCE & ZERO-COPYLEFT GUARANTEE
--------------------------------------------------------------------------------

n8n-manager-mcp is engineered under strict architectural and governance
invariants: 100% Local-First, Zero-Egress by default, and unprivileged user-mode
execution (RunAsInvoker). All workflow listing, inspection, export, backup,
restore, and node schema introspection operations execute locally via standard
input/output (stdio) JSON-RPC 2.0 without requiring elevated administrative
privileges. Outbound HTTP requests only occur when communicating directly with
the caller-specified n8n instance API endpoint.

All direct runtime, transitive overrides, and development dependencies utilized
across n8n-manager-mcp are distributed under strictly permissive open-source
licenses (MIT, BSD-2-Clause, BSD-3-Clause, Apache-2.0).

There are zero viral copyleft (GPL / AGPL) dependencies in core runtime or
distribution packages (Zero-Copyleft isolation guarantee), ensuring maximum
safety and portability for enterprise adoption, AI agent tool dispatching, and
automated CI/CD environments.

RunAsInvoker Non-Elevation Certification:
n8n-manager-mcp operates strictly in standard unprivileged user space.
It requires zero administrative elevation, zero sudo/root privileges, and zero
system daemon registrations.

Zero-Egress Perimeter:
Local stdio operations, JSON snapshot creation, local audit trail appending,
and offline node schema lookups emit zero outbound network telemetry. Network
requests are restricted strictly to direct API interactions with the explicitly
configured n8n server target.
